# PROGRESS

> Рабочая память между сессиями. Обновляй по ходу работы, читай в начале новой сессии.

## Проект
Лендинг + B2B-каталог ООО «ИНВИТ» (бренд EUROBAND, Минск). React 19 + Vite 6 + Tailwind 4.
Репозиторий: https://github.com/farik9797/invit
Прод: https://farik9797.github.io/invit/ (GitHub Pages, ветка `gh-pages`)

## Команды
- `npm run dev` — дев-сервер на :3000
- `npm run build` — сборка в `dist/` (base `/invit/`)
- `npm run deploy` — сборка + публикация в ветку `gh-pages` (`scripts/deploy.sh`)
- `npx tsc --noEmit` — проверка типов

## Статус
Многостраничный сайт-каталог опубликован в светлом фирменном стиле, каталог наполнен
реальными товарами с invit.by, карточка товара — с галереей и полным описанием.

## Дизайн-система
Светлая тема по референсу qazgeomax.kz + цвета из логотипов (`src/index.css`, блок `@theme`):
белый фон `--color-surface`, чередование с `--color-surface-soft`, границы `--color-line`,
текст `--color-brand-navy`, акценты `--color-brand-blue` / `--color-brand-sky`,
CTA `--color-brand-red`. Один шрифт Onest (Google Fonts, подключён в `index.html`).
Тёмных топбара и подвала больше нет.

## ВАЖНО: EUROBAND — это только ленты
Вентиляцию, инструмент, крепёж, пену и герметики компания НЕ производит — это прямые поставки.
Список разделов с собственным производством: `TAPE_SUBCATEGORIES` в `src/lib/product.ts`.
Бейдж «Собственное производство» стоит только на 12 лентах. На главной ленты вынесены в
отдельный блок, остальное — строкой «Сопутствующие товары».

## Каталог
208 позиций выгружены с invit.by (структура разделов повторяет левое меню сайта):
- **Материалы для монтажа окон** (`materialy-dlya-okon`) — 176 позиций, 10 подразделов
- **Комплектующие для вентиляции** (`ventilyaciya`) — 32 позиции, 6 подразделов

У товаров: название, описание, преимущества, таблица технических характеристик,
размерный ряд, ссылка на техлист (PDF) и `sourceUrl` — адрес исходной страницы на invit.by.
Полное содержимое карточек (галерея + блоки описания в исходном порядке: заголовки, абзацы,
списки, таблицы, иллюстрации) лежит в `src/data/productContent.ts` и грузится динамическим
импортом — отдельным чанком только на странице товара (447 КБ, 80 КБ в gzip).
У 34 товаров 2+ фото, всего 58 дополнительных иллюстраций.
Бейдж «Собственное производство» проставляется автоматически, если в названии есть EUROBAND.

Скрипты выгрузки лежат во временной папке сессии (`crawl.py`, `extract.py`, `generate.py`,
`emit_ts.py`) — при следующем обновлении каталога их проще написать заново по этому описанию:
обход двух корневых разделов → сбор ссылок из блока `class="products"` (у товаров URL без
слеша на конце) → разбор карточки (`h1`, `div.desc`, `table.attribute`, ссылка на `/download/*.pdf`).

## Структура страниц
| Маршрут | Страница | Файл |
|---|---|---|
| `/` | Главная (сокращённая) | `src/pages/HomePage.tsx` |
| `/catalog` | Каталог: разделы + все позиции | `src/pages/CatalogPage.tsx` |
| `/catalog/:categorySlug` | Раздел с фильтром по подразделам (`?sub=`) | `src/pages/CategoryPage.tsx` |
| `/catalog/:categorySlug/:productSlug` | Карточка товара (slug = артикул в нижнем регистре) | `src/pages/ProductPage.tsx` |
| `/about` | О компании и производстве | `src/pages/AboutPage.tsx` |
| `/certificates` | Сертификаты | `src/pages/CertificatesPage.tsx` |
| `/news`, `/news/:newsId` | Новости и статья | `src/pages/NewsPage.tsx`, `NewsArticlePage.tsx` |
| `/contacts` | Контакты обоих офисов + форма КП | `src/pages/ContactsPage.tsx` |
| `/status` | Отслеживание заказа | `src/pages/OrderStatusPage.tsx` |
| `*` | 404 | `src/pages/NotFoundPage.tsx` |

Адреса собраны в одном месте — `src/routes.ts` (`paths.*`). Общая обвязка (шапка, подвал,
плавающие кнопки, модалки) — `src/components/Layout.tsx`. Смета КП и модалки живут в
`src/context/ShopContext.tsx` над роутером, поэтому корзина не сбрасывается при переходах.

На главной осталось: герой с каталог-сайдбаром, преимущества, направления производства,
баннер порезки, 4 хита продаж и короткий CTA. Полный каталог, форма КП, сертификаты, новости
и статус заказа уехали на свои страницы.

## ВАЖНО: синхронизация с Google AI Studio
Проект параллельно живёт в AI Studio (https://ai.studio/apps/4abf7e93-624e-4e29-a3ae-55e5da77e728).
Пуш из AI Studio **перезаписывает** репозиторий своим снапшотом: он уже один раз снёс
`package-lock.json`, `scripts/deploy.sh`, `PROGRESS.md`, `base` в `vite.config.ts`, title в `index.html`
и логотипы (коммит 1517f15). Правки были восстановлены ручным ребейзом.

Порядок работы, чтобы не терять код:
1. Перед правками в AI Studio — залить туда актуальную версию из репозитория
   (архив с логотипами: `~/Downloads/euroband-with-logo.zip`, пересобирается из текущего состояния).
2. После пуша из AI Studio — проверять `git log` и восстанавливать конфиг публикации, если он снесён.
3. Не редактировать один и тот же файл одновременно в репозитории и в студии.

## Мобильная версия
Проверено на 375px. Что сделано отдельно под телефон:
- шапка: поиск переехал в бургер-меню (в строке шапки для него нет места), в топбаре
  остаётся только телефон;
- герой: кнопки на всю ширину, уменьшенные отступы;
- раздел каталога: вместо бокового списка подразделов — прокручиваемая лента чипов,
  товары начинаются сразу под заголовком (`CategoryPage`, блок `lg:hidden`);
- вкладки в блоке о производстве прокручиваются горизонтально;
- длинные названия в плитках переносятся (`hyphens-auto break-words`);
- форма поиска заказа: кнопка под полем, а не поверх него.
Таблицы в описании товара скроллятся внутри своего контейнера — страница по горизонтали
не едет ни на одной странице.

## Ключевые решения (и почему)
- Деплой через ветку `gh-pages`, а не GitHub Actions: у токена `gh` нет scope `workflow`, пуш `.github/workflows/*` отклоняется. Чтобы включить CI-деплой: `gh auth refresh -s workflow`, затем вернуть workflow-файл.
- Основной синий оставлен `#0B5FA5` (не логотипный `#3D90CD`): светлый логотипный синий не даёт контраста с белым текстом на плашках. Логотипный синий используется как `brand-sky` для акцентов.
- Красный `#D91920` (из EUROBAND) вместо оранжевого `#F39200`: оранжевого нет в бренде, плюс с белым текстом он давал контраст ~2.4:1 (красный — 5.1:1).
- SVG-логотипы получены кропом viewBox из `.ai` (PDF) + удалением путей вне viewBox — файлы уменьшились с 71K до 18K.
- Роутинг на `react-router-dom` с обычными URL (не хэш) — ради SEO. На GitHub Pages прямые ссылки
  работают через `404.html` (копия `index.html`, делается в `scripts/deploy.sh`); статус ответа при
  этом 404, поэтому на боевом хостинге invit.by нужно настроить обычный SPA-rewrite на `index.html`.
- `basename` роутера берётся из `import.meta.env.BASE_URL`, поэтому один и тот же код работает и на
  `/` в разработке, и на `/invit/` на GitHub Pages.
