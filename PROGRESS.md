# PROGRESS

> Рабочая память между сессиями. Обновляй по ходу работы, читай в начале новой сессии.

## Проект
Лендинг + B2B-каталог ООО «ИНВИТ» (бренд EUROBAND, Минск). React 19 + Vite 6 + Tailwind 4.
Репозиторий: https://github.com/farik9797/invit
Прод: https://farik9797.github.io/invit/ (GitHub Pages, ветка `gh-pages`)

## Команды
- `npm run dev` — дев-сервер на :3000
- `npm run build` — сборка в `dist/` (base `/invit/`)
- `npm run deploy` — сборка + публикация в ветку `gh-pages` (`scripts/deploy.sh`)
- `npx tsc --noEmit` — проверка типов

## Статус
Многостраничный сайт-каталог опубликован. Ждём правок от клиента.

## Структура страниц
| Маршрут | Страница | Файл |
|---|---|---|
| `/` | Главная (сокращённая) | `src/pages/HomePage.tsx` |
| `/catalog` | Каталог: разделы + все позиции | `src/pages/CatalogPage.tsx` |
| `/catalog/:categorySlug` | Раздел с фильтром по подразделам (`?sub=`) | `src/pages/CategoryPage.tsx` |
| `/catalog/:categorySlug/:productSlug` | Карточка товара (slug = артикул в нижнем регистре) | `src/pages/ProductPage.tsx` |
| `/about` | О компании и производстве | `src/pages/AboutPage.tsx` |
| `/certificates` | Сертификаты | `src/pages/CertificatesPage.tsx` |
| `/news`, `/news/:newsId` | Новости и статья | `src/pages/NewsPage.tsx`, `NewsArticlePage.tsx` |
| `/contacts` | Контакты обоих офисов + форма КП | `src/pages/ContactsPage.tsx` |
| `/status` | Отслеживание заказа | `src/pages/OrderStatusPage.tsx` |
| `*` | 404 | `src/pages/NotFoundPage.tsx` |

Адреса собраны в одном месте — `src/routes.ts` (`paths.*`). Общая обвязка (шапка, подвал,
плавающие кнопки, модалки) — `src/components/Layout.tsx`. Смета КП и модалки живут в
`src/context/ShopContext.tsx` над роутером, поэтому корзина не сбрасывается при переходах.

На главной осталось: герой с каталог-сайдбаром, преимущества, направления производства,
баннер порезки, 4 хита продаж и короткий CTA. Полный каталог, форма КП, сертификаты, новости
и статус заказа уехали на свои страницы.

## Ключевые решения (и почему)
- Деплой через ветку `gh-pages`, а не GitHub Actions: у токена `gh` нет scope `workflow`, пуш `.github/workflows/*` отклоняется. Чтобы включить CI-деплой: `gh auth refresh -s workflow`, затем вернуть workflow-файл.
- Основной синий оставлен `#0B5FA5` (не логотипный `#3D90CD`): светлый логотипный синий не даёт контраста с белым текстом на плашках. Логотипный синий используется как `brand-sky` для акцентов.
- Красный `#D91920` (из EUROBAND) вместо оранжевого `#F39200`: оранжевого нет в бренде, плюс с белым текстом он давал контраст ~2.4:1 (красный — 5.1:1).
- SVG-логотипы получены кропом viewBox из `.ai` (PDF) + удалением путей вне viewBox — файлы уменьшились с 71K до 18K.
- Роутинг на `react-router-dom` с обычными URL (не хэш) — ради SEO. На GitHub Pages прямые ссылки
  работают через `404.html` (копия `index.html`, делается в `scripts/deploy.sh`); статус ответа при
  этом 404, поэтому на боевом хостинге invit.by нужно настроить обычный SPA-rewrite на `index.html`.
- `basename` роутера берётся из `import.meta.env.BASE_URL`, поэтому один и тот же код работает и на
  `/` в разработке, и на `/invit/` на GitHub Pages.
