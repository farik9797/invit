# Тема «INVIT EUROBAND»

Тема WordPress для сайта ООО «ИНВИТ»: каталог на WooCommerce, заявка на
счёт-фактуру вместо розничной корзины, содержимое правится через ACF Pro.

## Что внутри

| Файл | Зачем |
|---|---|
| `functions.php` | подключение стилей, поддержка Woo, помощники `invit_field()` / `invit_option()` |
| `header.php`, `footer.php` | шапка с мегаменю и подвал с оговоркой о работе без розницы |
| `front-page.php` | главная: слайдер, разделы каталога, преимущества, ленты EUROBAND |
| `index.php` | новости и запасной шаблон |
| `template-parts/mega-menu.php` | выпадающее меню разделов каталога |
| `template-parts/modal-request.php` | окно «Запросить расчёт» |
| `template-parts/modal-search.php` | окно поиска для узкого экрана |
| `woocommerce/content-product-card.php` | карточка товара в списках |
| `inc/acf-fields.php` | поля ACF Pro: настройки сайта и главная |
| `inc/icons.php` | значки Lucide, скопированные из набора (руками не рисуем) |
| `inc/nav-walker.php` | плоское меню шапки |
| `woocommerce/archive-product.php` | каталог: колонка разделов, поиск, сортировка, сетка |
| `woocommerce/single-product.php` | карточка товара: галерея, характеристики, соседи по разделу |
| `template-parts/catalog-sidebar.php` | колонка разделов каталога |
| `woocommerce/cart/cart.php` | лист заявки: позиции, количество, итог по штукам |
| `woocommerce/checkout/form-checkout.php` | форма заявки на счёт-фактуру |
| `woocommerce/checkout/thankyou.php` | экран «Заявка на счёт принята» |
| `inc/checkout.php` | поля заявки, проверка УНП, оговорка и подтверждение статуса |
| `page-about.php`, `page-contacts.php`, `page-certificates.php` | шаблоны страниц |
| `page.php`, `single.php`, `woocommerce.php` | обычная страница, новость, обёртка Woo |

## Стили

CSS собирается Tailwind из `assets/css/source.css` в `assets/css/app.css`.
После правки классов в шаблонах пересобрать:

```bash
npx @tailwindcss/cli -i invit-theme/assets/css/source.css -o invit-theme/assets/css/app.css --minify
```

Собранный `app.css` лежит в теме: на хостинге Node не нужен.

## Установка у клиента

1. Поставить и включить **ACF Pro** (повторители, страница настроек и галерея —
   только в Pro) и **WooCommerce**.
2. Загрузить тему и включить её.
3. Создать страницу «Главная», в «Настройки → Чтение» назначить её главной.
4. «Настройки → Постоянные ссылки» — любой вариант, кроме «Простые».
5. Заполнить «Настройки сайта» (телефоны, почта, Telegram, реквизиты, оговорка).
6. Импортировать каталог: `scripts/export-woocommerce.py` делает CSV,
   `scripts/wp-import-products.php` заливает его через WP-CLI. Адреса товаров и
   разделов берутся из колонок `Slug` и `Category slugs` — латиницей, как на
   нынешнем сайте; иначе WordPress сделал бы их из русских названий.

## Особенности

- Утилиты Tailwind подключены **вне CSS-слоя** (`@import "tailwindcss/utilities.css"`
  без `layer`): WordPress и Woo выводят свои стили без слоя, а неслоёное правило
  побеждает любое слоёное независимо от специфичности.
- Стили WooCommerce отключены целиком (`woocommerce-layout`, `woocommerce-smallscreen`,
  `woocommerce-general`): правило `.woocommerce img {height:auto}` ломало высоту
  картинок. То немногое, что рисует сам Woo — уведомления, поле количества,
  таблица состава заявки — оформлено в `assets/css/source.css`.
- Страницы «Заявка на счёт» и «Оформление заявки» должны содержать классические
  шорткоды `[woocommerce_cart]` и `[woocommerce_checkout]`: блочная корзина Woo
  шаблоны темы не использует.
- Адреса каталога повторяют прежний сайт: `/catalog/`, `/catalog/<раздел>/`,
  `/catalog/<раздел>/<товар>/`. Настройка: в `woocommerce_permalinks`
  `product_base` = `/catalog/%product_cat%`, `category_base` = `catalog`,
  страница магазина со слагом `catalog`. Остальное делает `inc/permalinks.php`:
  короткая ссылка товара (только верхний раздел), короткий адрес раздела и
  подраздела одним уровнем и снятие двух перенаправлений — канонического
  WordPress и `wc_product_canonical_redirect` Woo, которые зацикливали 301.
- Цены показываются в виде «26,47 р.»: формат задан в `functions.php`, чтобы не
  потерялся при переносе на другой сервер.
- У логотипов в SVG убраны атрибуты `width`/`height` в пунктах: браузер считал
  их собственным размером и растягивал картинку на 528px.

## Установка каталога и страниц

Кроме шагов выше, создать страницы и назначить шаблоны: «О компании» →
`page-about.php`, «Контакты» → `page-contacts.php`, «Документация» →
`page-certificates.php`; страницу «Новости» указать в «Настройки → Чтение».
Способ оплаты — «Оплата при доставке» переименовать в «Счёт-фактура».
