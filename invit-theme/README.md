# Тема «INVIT EUROBAND»

Тема WordPress для сайта ООО «ИНВИТ». Показывает сайт **точь-в-точь как
React-версия** (`src/`, https://farik9797.github.io/invit/): та же разметка, те
же классы Tailwind, те же токены и логика каталога. Товары, снимки и заказы — в
WooCommerce, остальное (разделы, новости-исходники, документы, реквизиты,
подробные описания) — из данных React-сайта.

Правило: правите React — переносите сюда, иначе два сайта разойдутся. Сверка
делается отпечатком раскладки (положение и размер каждого элемента по блокам)
на 1440 и 375 px.

## Сборка и выкладка

```bash
bash scripts/deploy-theme.sh
```

Скрипт собирает данные и картинки (`scripts/build-theme-data.sh` копирует из
`src/assets`, `public/docs` и выгружает `data/site.json`), стили Tailwind и
загружает тему по FTP в безопасном порядке. Доступы — из `password.md`.
Картинки, документы и `site.json` в git не лежат: их делает сборка.

Новый значок Lucide: добавить имя в `EXTRA` скрипта `scripts/build-theme-icons.py`
и запустить его.

## Как устроен каталог

React держит 8740 товаров в браузере. Тема делает то же на сервере: товары
собираются в компактный индекс (`uploads/invit-cache/catalog-v*.php`), отбор,
поиск (транслит, раскладка, артикулы, веса) и порядок перенесены из
`catalogFilters.ts`, `search.ts`, `productSize.ts`, `product.ts` построчно.
Индекс сбрасывается при сохранении товара и при новой выгрузке `site.json`.

Отбор живёт в адресе (`?sub=`, `?q=`, `?brand=`, `?country=`, `?d=`, `?l=`,
`?sort=`), смена отбора подменяет содержимое страницы без перезагрузки.
Мега-меню приходит отдельным запросом при первом наведении (`wc-ajax=invit_mega`).

## Описания разделов

Тексты разделов со старого invit.by (монтажный шов, ПСУЛ, пена, герметики,
ленты ПЭС, уплотнитель EPDM, уголки, цинк-спрей) собирает
`scripts/build-category-info.py` в `data/category-info.json`: разметка
очищена, ссылки переведены на новые адреса. Тема один раз заносит их в
описание категории WooCommerce, дальше текст правится в админке
(Товары → Категории → Описание). Над товарами стоит описание подраздела
(`?sub=` или `/catalog/<подраздел>/`), иначе раздела; при поиске не выводится.

## Заявка на счёт

Корзина WooCommerce, но страница своя (как CartPage.tsx): позиции и реквизиты
рядом. Отправка создаёт заказ Woo «В обработке» со способом оплаты
«Счёт-фактура», УНП в мете `_billing_unp`. Страница оформления Woo
перенаправляет на заявку. Цены на витрине выключены, как в React
(`PRICES_SHOWN = false`), в заказ они попадают.

## Особенности

- Утилиты Tailwind подключены **вне CSS-слоя**: WordPress и Woo выводят стили без
  слоя, а неслоёное правило побеждает любое слоёное.
- Стили и скрипты WooCommerce отключены: тема их не использует.
- Типографская замена WordPress выключена: React выводит текст как есть.
- Адреса каталога: `/catalog/`, `/catalog/<раздел>/`, `/catalog/<раздел>/<товар>/`
  (`inc/permalinks.php`). Поиск WordPress по товарам ведёт на `/catalog/?q=`.
- Поля ACF Pro (`inc/acf-fields.php`) зарегистрированы, но тексты страниц теперь
  взяты из React дословно; подключить их к шаблонам — отдельная задача.
