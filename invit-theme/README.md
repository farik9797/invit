# Тема «INVIT EUROBAND»

Тема WordPress для сайта ООО «ИНВИТ»: каталог на WooCommerce, заявка на
счёт-фактуру вместо розничной корзины, содержимое правится через ACF Pro.

## Что внутри

| Файл | Зачем |
|---|---|
| `functions.php` | подключение стилей, поддержка Woo, помощники `invit_field()` / `invit_option()` |
| `header.php`, `footer.php` | шапка с мегаменю и подвал с оговоркой о работе без розницы |
| `front-page.php` | главная: слайдер, разделы каталога, преимущества, ленты EUROBAND |
| `index.php` | новости и запасной шаблон |
| `template-parts/mega-menu.php` | выпадающее меню разделов каталога |
| `template-parts/modal-request.php` | окно «Запросить расчёт» |
| `template-parts/modal-search.php` | окно поиска для узкого экрана |
| `woocommerce/content-product-card.php` | карточка товара в списках |
| `inc/acf-fields.php` | поля ACF Pro: настройки сайта и главная |
| `inc/icons.php` | значки Lucide, скопированные из набора (руками не рисуем) |
| `inc/nav-walker.php` | плоское меню шапки |

## Стили

CSS собирается Tailwind из `assets/css/source.css` в `assets/css/app.css`.
После правки классов в шаблонах пересобрать:

```bash
npx @tailwindcss/cli -i invit-theme/assets/css/source.css -o invit-theme/assets/css/app.css --minify
```

Собранный `app.css` лежит в теме: на хостинге Node не нужен.

## Установка у клиента

1. Поставить и включить **ACF Pro** (повторители, страница настроек и галерея —
   только в Pro) и **WooCommerce**.
2. Загрузить тему и включить её.
3. Создать страницу «Главная», в «Настройки → Чтение» назначить её главной.
4. «Настройки → Постоянные ссылки» — любой вариант, кроме «Простые».
5. Заполнить «Настройки сайта» (телефоны, почта, Telegram, реквизиты, оговорка).
6. Импортировать каталог: `scripts/export-woocommerce.py` делает CSV,
   `scripts/wp-import-products.php` заливает его через WP-CLI.
