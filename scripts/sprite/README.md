# Иконки разделов из спрайта invit.by

Знаки подразделов на сайте — **готовые файлы клиента** из
`src/assets/sections/`. Эти скрипты вытаскивают знаки из растрового спрайта
invit.by и нужны на случай, если появится раздел, для которого готового файла
нет: тогда `gen-ts.py` соберёт `src/lib/sectionIconPaths.ts`, а `SectionIcon`
надо будет снова научить его читать (см. историю коммитов).

## Что откуда

- `sprite.png` — снят с `https://invit.by/catalog/view/theme/meta/img/sprite.png`.
  Растр 25x425: семнадцать знаков по 25x25 (шестнадцать разделов + антикоррозийный
  спрей, которого в нашем каталоге нет).
- Соответствие «ячейка -> раздел» взято из их же CSS (`catalog/view/theme/meta/css/style.css`):
  класс `.icoNN` со сдвигом фона, где `NN - 61` = номер ячейки. Названия разделов —
  из разметки главной, из подписи рядом с этим `span`.

## Как пересобрать

```
python3 trace.py     # sprite.png -> out/cell-NN.svg
python3 gen-ts.py    # out/*.svg  -> src/lib/sectionIconPaths.ts
```

`trace.py` увеличивает ячейку в 20 раз, размывает (иначе potrace обводит
«лесенку» исходных пикселей) и трассирует в два тоновых слоя: тёмный корпус и
светлый торец. Порог между ними — `LIGHT_CUT`. Оба слоя красятся `currentColor`,
светлый с прозрачностью 0.4, поэтому знак берёт цвет текста.

Нужен `potrace` (`brew install potrace`) и Pillow.

`src/lib/sectionIconPaths.ts` руками не правится — он перезаписывается скриптом.
