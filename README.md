# Сайт ООО «ИНВИТ» — ленты EUROBAND

Многостраничный сайт-каталог белорусского производителя уплотнительных и герметизирующих
лент EUROBAND. React 19 + Vite 6 + Tailwind 4 + react-router-dom.

Прод: https://farik9797.github.io/invit/

## Запуск

```
npm install
npm run dev      # дев-сервер на :3000
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер на порту 3000 |
| `npm run build` | Прод-сборка в `dist/` (base `/invit/`) |
| `npm run deploy` | Сборка + публикация в ветку `gh-pages` |
| `npm run lint` | Проверка типов (`tsc --noEmit`) |

## Структура

- `src/pages/` — страницы: главная, каталог, раздел, товар, о компании, документы,
  новости, контакты, статус заказа, 404
- `src/components/` — общая обвязка (`Layout`, `Header`, `Footer`), карточка товара,
  галерея с лайтбоксом, блоки главной в `components/home/`
- `src/data/catalogData.ts` — витрина каталога: 12 разделов и 5105 карточек, плюс
  слайды главной, документы и новости
- `src/data/catalog.generated.ts` — сами разделы и товары, собраны скриптом; руками
  не правятся
- `src/data/siteCatalogSource.ts` — прежний каталог сайта, приложение его не читает:
  это исходник для `scripts/merge-site.py`
- `src/data/productContent.ts` — полное описание карточек (грузится отдельным чанком)
- `src/routes.ts` — все адреса страниц в одном месте
- `src/index.css` — дизайн-токены в блоке `@theme`

## Важно

**EUROBAND — это только ленты.** Пена, герметики, крепёж, инструмент и комплектующие для
вентиляции — прямые поставки, не собственное производство. Разделы с производством
перечислены в `TAPE_SUBCATEGORIES` (`src/lib/product.ts`).

Фото товаров лежат в `public/products/` (1996 файлов, имя файла — адрес товара).
Собирает их `scripts/build-catalog.py`; отдельными импортами они не подключаются.

## Каталог: как пересобрать

Витрина собрана заранее — `npm run dev` и `npm run build` работают на голом
репозитории. Скрипты нужны, только когда каталог меняется: пришла новая выгрузка
поставщика или правится дерево разделов.

```
python3 scripts/build-woocommerce.py   # каталог клиента + лестницы
python3 scripts/build-osnastka.py      # + оснастка
python3 scripts/merge-site.py          # + товары сайта   -> woocommerce_import_merged.csv
python3 scripts/build-variations.py    # свод вариаций    -> woocommerce_import_variations.csv
python3 scripts/build-catalog.py       # витрина          -> src/data + public/products
```

Ещё два скрипта отдельно от конвейера: `scripts/sections/draw.py` перерисовывает знаки
разделов, а `scripts/build-site-export.py` делает выгрузку каталога из админки invit.by —
он читает снимок админки `files/invit-admin-dump.json` (1,5 МБ), который без доступа
в админку заново не собрать.

## Данные (`files/`) — что копировать на новую машину

Папки нет в git: там архив фото на 1.1 ГБ и выгрузки поставщиков. Скрипты выше читают
и пишут именно её, поэтому без неё каталог не пересобрать.

Исходники — их взять неоткуда, копировать обязательно:

| Файл | Размер | Что это |
|---|---|---|
| `by-full.zip` | 1.1 ГБ | архив фото поставщика: лестницы и оснастка |
| `Круги_буры_оснастка.csv` | 3.2 МБ | выгрузка поставщика, 3388 позиций оснастки |
| `Лестницы_стремянки.csv` | 232 КБ | выгрузка поставщика, лестницы и стремянки |
| `invit-katalog.xlsx` | 68 КБ | каталог клиента: что оставить в выгрузке |
| `site-photos/` | 7,6 МБ, 802 файла | фото импортированного крепежа |
| `woocommerce_import.before-ladders.csv` | 5,7 МБ | снимок выгрузки до лестниц |
| `woocommerce_import.before-osnastka.csv` | 5,9 МБ | снимок выгрузки до оснастки |

Снимки `before-*` держат конвейер повторяемым: скрипты читают их, а не собственный
результат, поэтому цепочку можно гонять сколько угодно раз подряд.

Остальное в `files/` — промежуточное и отчёты, всё пересоздаётся: `images/` (78 МБ,
фото, приведённые к одному виду), `woocommerce_import*.csv`, `оснастка.*`,
`выгрузка-сайта.*` и таблицы на проверку.
