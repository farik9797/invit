# Сайт ООО «ИНВИТ» — ленты EUROBAND

Многостраничный сайт-каталог белорусского производителя уплотнительных и герметизирующих
лент EUROBAND. React 19 + Vite 6 + Tailwind 4 + react-router-dom.

Прод: https://farik9797.github.io/invit/

## Запуск

```
npm install
npm run dev      # дев-сервер на :3000
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер на порту 3000 |
| `npm run build` | Прод-сборка в `dist/` (base `/invit/`) |
| `npm run deploy` | Сборка + публикация в ветку `gh-pages` |
| `npm run lint` | Проверка типов (`tsc --noEmit`) |

## Структура

- `src/pages/` — страницы: главная, каталог, раздел, товар, о компании, документы,
  новости, контакты, статус заказа, 404
- `src/components/` — общая обвязка (`Layout`, `Header`, `Footer`), карточка товара,
  галерея с лайтбоксом, блоки главной в `components/home/`
- `src/data/catalogData.ts` — каталог: категории, 208 товаров, документы, новости
- `src/data/productContent.ts` — полное описание карточек (грузится отдельным чанком)
- `src/routes.ts` — все адреса страниц в одном месте
- `src/index.css` — дизайн-токены в блоке `@theme`

## Важно

**EUROBAND — это только ленты.** Пена, герметики, крепёж, инструмент и комплектующие для
вентиляции — прямые поставки, не собственное производство. Разделы с производством
перечислены в `TAPE_SUBCATEGORIES` (`src/lib/product.ts`).

Изображения товаров и документов отдаются прямыми ссылками с invit.by.
